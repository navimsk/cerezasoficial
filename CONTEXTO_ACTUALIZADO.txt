1. QUÉ ES
======================================================================
Contador automático de cajas para un packing de cerezas.
Sensor retrorreflectivo Metaltex P18R  ->  ESP32 industrial USR-EG118  ->  Supabase  ->  app web PWA.
No hay metas de producción: todo se compara con el propio historial.
Regla de oro: el conteo de cajas = SUMA de la columna n de la tabla eventos (no la cantidad de filas).

4. CÓMO FUNCIONA EL FLUJO
======================================================================
Firmware (conteo.h):
- Lee el sensor cada 1 ms. Estados: LIBRE, VALIDANDO, EN_CAJA, ATASCO.
- Bloqueo >= bloqueoMinMs (100 ms) = caja (+1, tipo "caja"). Huecos < huecoMinMs (30 ms) no separan cajas.
- Cajas pegadas: estima por avance de la cinta (velocidad x tiempo); +1 por cada largo de caja (tipo "caja_est").
- Atasco: si el bloqueo supera maxPegadas (4) cajas, revierte las estimadas (evento "ajuste", n negativo),
  emite atasco_inicio y deja de contar hasta atasco_fin.
- Velocidad: se aprende sola con la MEDIANA de las últimas 7 cajas AISLADAS; empieza a usarla desde la 3.ª.
  Solo acepta mediciones entre velMinMmS (100) y velMaxMmS (1500 mm/s). Se reinicia al apagar.
Envío (.ino):
- Cada evento lleva seq correlativo guardado en memoria permanente (no se repite tras reinicio).
- Cola en RAM, lotes de hasta 25, POST a /functions/v1/ingesta con cabecera x-equipo-token.
- (equipo_id, seq) es único en la base: reenviar nunca duplica.
- Heartbeat cada 30 s. Hora por NTP (zona Chile).
Supabase:
- Tabla eventos (dato bruto) + agregados agg_minuto/agg_hora/agg_dia por trigger.
- RPC para la app: resumen_vivo, serie, salud_equipos, atascos_rango, datos_proyeccion, primer_dato.
- RLS: solo leen los correos en usuarios_autorizados.
- pg_cron cada minuto -> función vigilar -> push (atasco, >2 min sin contacto, caída de ritmo). Push aún NO configurado (faltan claves VAPID).
App:
- Pantallas: En vivo (Realtime), Historial, Proyecciones, Exportar (Excel/CSV/SQL), Equipos, Ajustes.
- Sin .env arranca en modo demo con datos simulados.
- Correr local: cd web && npm run dev  ->  http://localhost:5173

6. PROBLEMAS ABIERTOS (al 18-11-2026)
======================================================================
A) LOS EVENTOS NO LLEGAN A SUPABASE. El ESP32 cuenta bien (se ve en el monitor serie), pero la tabla
   eventos tiene 0 filas. La URL y el token están verificados como correctos.
   Causa más probable: el ESP32 nunca se conecta al WiFi (hotspot de iPhone). El firmware anterior no
   avisaba nada si el WiFi nunca conectaba.
   - Se agregó diagnóstico: al encender lista las redes visibles (marca "->" la configurada) y, sin
     conexión, imprime cada 10 s el motivo (no encuentra la red / clave incorrecta) y eventos pendientes.
   - Sospecha: el SSID está escrito "IPhone de José" (I mayúscula); los iPhone suelen llamarse
     "iPhone de José" (i minúscula). Mayúsculas, tildes y espacios cuentan.
   - En el iPhone: activar "Maximizar compatibilidad" (2,4 GHz) y dejar abierta la pantalla de Compartir Internet.
   - SIGUIENTE PASO: subir el firmware nuevo, abrir monitor serie a 115200, presionar RESET y revisar
     las primeras líneas (lista de redes y estado WiFi). Debe aparecer "WiFi: conectado ...".

B) VELOCIDAD FUERA DE RANGO. Con velInicialMmS = 2000, si la cinta realmente va a ~2 m/s, todas las
   mediciones se descartan (límite 1500) y nunca aprende. Solución: agregar en crearConfig()
     c.velMaxMmS = 3000;
   Además conviene medir la velocidad real de la cinta (cronometrar 1 metro).
   Con 235 mm a 2000 mm/s una caja tapa el haz ~117 ms: bloqueoMinMs = 100 está al límite, NO subirlo.

C) "EL SENSOR ES MUY SENSIBLE". Falta saber el síntoma exacto:
   - Si cuenta cosas que no son cajas (manos, hojas): subir bloqueoMinMs (cuidado con B).
   - Si una caja se cuenta como dos (calados/asas de la caja, rebotes): subir huecoMinMs (ej. 60–80)
     y/o mover el haz a una altura donde la caja sea sólida.
   - Hardware: alinear bien el reflector; ajustar sensibilidad si el modelo tiene tornillo.

7. CÓMO SUBIR EL FIRMWARE DESDE VS CODE (sin instalar nada extra)
======================================================================
En la terminal de VS Code (PowerShell), desde la carpeta del proyecto:
  Set-Alias arduino "C:\Program Files\Arduino IDE\resources\app\lib\backend\resources\arduino-cli.exe"
  arduino board list
  arduino compile --fqbn esp32:esp32:esp32da firmware/contador_eg118
  arduino upload  --fqbn esp32:esp32:esp32da -p COM3 firmware/contador_eg118
  arduino monitor -p COM3 --config baudrate=115200
Si se queda en "Connecting....." mantener BOOT. Cerrar el monitor antes de volver a subir.
Para compilar se necesita secretos.h (copiar secretos.example.h y completarlo).
